# kiks

`kiks` — локальное приложение на `React + TypeScript` для планирования подготовки по армрестлингу. Оно собрано вокруг трёх сценариев: дашборд прогресса, планирование циклов и календарь столовых тренировок.

## Стек

- `React 19` + `TypeScript`
- `Vite`
- `Material UI` + `@mui/x-date-pickers`
- `React Router v6`
- `React Hook Form`
- `Zod` + `@hookform/resolvers`
- `Zustand` + `persist`
- `ESLint` + `Prettier`

## Запуск

```bash
npm install
npm run dev
```

## Что реализовано

- Главная страница `kiks` показывает недельную нагрузку, число столовых сессий, динамику пронации, текущий стрик и карту акцентов по кисти, пальцам, лучу и боковому давлению.
- Планирование вынесено в отдельный экран: можно создавать циклы подготовки, собирать тренировочные дни и прикреплять к ним движения из armwrestling-библиотеки.
- Внутри каждого тренировочного дня есть структурированный `План на тренировку` с рабочими подходами, моментами отработки и тезисами “на чем делать акцент во время борьбы”.
- Библиотека движений хранит профильные шаблоны: работа на столе, пронация, удержание кисти, боковое давление, пальцы, луч и нужный инвентарь.
- Детальная страница цикла показывает и библиотеку движений дня, и сам план тренировки по каждому дню.
- Календарь отображает выполненные, пропущенные и запланированные armwrestling-сессии.
- Настройки сохраняются в `localStorage`, включая тему, размер шрифта, уведомления и пользовательские предпочтения.

## Почему формы и store устроены так

- `CreateProgramDrawer` использует `React Hook Form` и `Zod`, потому что день подготовки теперь хранит вложенную структуру: акценты, выбранные движения, рабочие подходы, drill-моменты и match focus points.
- `Zustand persist` нужен, чтобы циклы, календарь и планы не терялись после перезагрузки.
- Seed data сразу отражают домен армрестлинга, а не универсального gym tracker.
- Интерфейс остаётся product-like: это не текстовый блокнот, а трекер подготовки под борьбу на руках.

## Ограничение текущей версии

В текущей версии нет отдельного live-экрана проведения поединка или режима отметки подходов прямо во время тренировки. `kiks` фокусируется на планировании, аналитике и календаре подготовки.
